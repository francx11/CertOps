# CertOps

> Universal framework for cloud certification exam preparation — from raw HTML question dumps to a full interactive quiz engine and web dashboard.

CertOps provides an end-to-end pipeline: scrape and normalize question banks, validate them against a strict JSON schema, study theory guides, and drill with a terminal quiz engine or a React web UI.

---

## Features

- **ETL pipeline** — converts raw HTML question dumps into a normalized, schema-validated JSON question bank
- **Terminal quiz engine** — one question at a time with immediate feedback, explanations, and per-domain stats
- **Terminal exam simulator** — fixed-count, countdown timer, pass/fail at 70% — mirrors real exam conditions
- **Web dashboard** — React + TypeScript UI to browse, filter, and answer questions in the browser
- **Theory study guides** — Markdown domain summaries (Spanish) auto-generated by Claude AI
- **Stable question IDs** — SHA-256 fingerprint of each question stem; IDs never change after ingest
- **CI validation** — GitHub Actions validates every question bank against the JSON schema on every push/PR

---

## Architecture

```
certifications/<cert>/raw/*.html
          │
    [scripts/ingest_html.py]   ← ETL: HTML → JSON
          │
certifications/<cert>/questions.json
          │
      [core/engine.py]         ← Quiz / Exam CLI
          │
        terminal

[web/]                         ← React web dashboard
[core/schema.json]             ← validates all question banks
[.github/workflows/validate.yml] ← CI runs on push / PR
```

## Tech Stack

| Layer | Technology |
|-------|-----------|
| **ETL / Ingest** | Python 3.11+, BeautifulSoup-style HTML parsing, `hashlib` SHA-256 |

| **Terminal engine** | Python 3.11+, `rich` (panels, colors, progress), `argparse` |
| **Web UI** | React 19, TypeScript, Vite 8, Tailwind CSS, lucide-react |
| **Package manager** | pnpm |
| **CI** | GitHub Actions |
| **AI tooling** | Claude Code (slash commands for ingest, quiz, theory generation) |

## Quick Start

### Prerequisites

```bash
python --version    # 3.11+
pip install jsonschema rich
```

### Ingest HTML question dumps

```bash
python scripts/ingest_html.py \
  --input  certifications/aws-ai-practitioner/raw/ \
  --output certifications/aws-ai-practitioner/questions.json
```

### Run a 20-question quiz

```bash
python core/engine.py --cert aws-ai-practitioner --mode quiz --count 20 --shuffle
```

### Run a full simulated exam

```bash
python core/engine.py --cert aws-ai-practitioner --mode exam --count 65
```

### Launch the web dashboard

```bash
cd web
pnpm install
pnpm dev
```

## CLI Reference

### Quiz / Exam Engine (`core/engine.py`)

| Flag | Description |
|------|-------------|
| `--cert <slug>` | Required. Certification slug (e.g. `aws-ai-practitioner`) |
| `--mode quiz\|exam` | Default: `quiz` |
| `--domain "Domain 1"` | Filter questions to a single domain |
| `--count N` | Number of questions |
| `--shuffle` | Randomize question order |
| `--seed 42` | Reproducible shuffle |
| `--time-limit 90` | Exam timer in minutes (default: 90) |
| `--no-explanations` | Hide explanations after each quiz answer |
| `--list-certs` | List available certifications and exit |

**Quiz mode** — one question at a time, immediate feedback + explanation, per-domain summary at the end.

**Exam mode** — fixed count, countdown timer, no answer feedback until the end, pass/fail at 70%.

### Ingest Script (`scripts/ingest_html.py`)

| Flag | Description |
|------|-------------|
| `--input PATH` | HTML file or directory of HTML files (required) |
| `--output PATH` | Output `questions.json` path (required) |
| `--domain "..."` | Domain tag applied to all ingested questions (default: `General`) |
| `--dry-run` | Report counts without writing anything |
| `--verbose` | Print per-file details |

Supports two HTML formats:
- **Custom viewer** — `div.question` + `div.correct-answer` structure
- **Heuristic fallback** — generic Q&A HTML patterns

HOTSPOT questions (image-based drag-drop) are automatically detected and skipped.

## Question Bank Schema

Each entry in `questions.json`:

| Field | Type | Constraints |
|-------|------|-------------|
| `id` | string | 12 lowercase hex chars (SHA-256 of normalized stem) |
| `domain` | string | Non-empty |
| `question` | string | Min 10 chars |
| `options` | object | Keys A–F only, 2–6 entries |
| `correct` | string or array | `"A"`–`"F"` or sorted list for multi-select |
| `explanation` | string | Non-empty |
| `source` | string | Source HTML filename |
| `tags` | array | Unique strings |
| `added` | string | ISO date `YYYY-MM-DD` |

## Adding a New Certification

1. Create `certifications/<cert-slug>/`
2. Place HTML dump files in `certifications/<cert-slug>/raw/`
3. Optionally add Markdown study guides to `certifications/<cert-slug>/theory/`
4. Run ingest:
   ```bash
   python scripts/ingest_html.py \
     --input  certifications/<cert-slug>/raw/ \
     --output certifications/<cert-slug>/questions.json
   ```
5. Push — CI validates the new bank automatically.

## Contribution Rules

- **Never manually edit `questions.json`** — always use `ingest_html.py`
- **IDs are stable** — do not regenerate them after a question enters the bank
- Run `--dry-run` before committing a new ingest to review what will be added
- Theory files live in `theory/` as Markdown; all content in **Spanish**
- Raw HTML files in `raw/` are gitignored — only commit if fully anonymized
